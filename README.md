# 📍 Buscar CEP

Uma aplicação web prática e rápida para consulta de Códigos de Endereçamento Postal (CEP). O projeto consome uma API externa para buscar os dados de endereço automaticamente assim que o usuário digita um CEP válido.

## 🎯 Objetivo do Projeto

Demonstrar na prática o consumo de APIs REST no front-end, manipulação de dados assíncronos (Promises/Async Await) e preenchimento dinâmico de formulários baseados na resposta do servidor. É uma funcionalidade real e extremamente comum em sistemas de e-commerce e cadastros.

## ✨ Funcionalidades

- **Busca Dinâmica:** Retorna Rua, Bairro, Cidade e Estado baseados no CEP digitado.
- **Preenchimento Automático:** Os campos de endereço são populados automaticamente após a busca.
- **Tratamento de Erros:** Validação de CEPs inválidos (quantidade de números incorreta) e CEPs não encontrados na base de dados.
- **Consumo de API:** Integração direta com a API pública do [ViaCEP](https://viacep.com.br/).

## 🛠️️ Tecnologias Utilizadas

- **HTML5 ** - Estrutura do formulário de busca e exibição dos dados.
- ** CSS3 ** - Estilização da interface de usuário.
- **JavaScript ** - Lógica de validação e requisições HTTP utilizando a `Fetch API`.
